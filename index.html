Payments that keep receipts private.

Opacus fuses the proven Monero transaction model (ring-CT semantics, stealth addresses, Pedersen commitments) with Zcash-style Halo2 FCMP++ spend proofs: every spend carries a succinct zero-knowledge proof that its key material belongs to the global set of all wallet keys — and reveals nothing else.

How the privacy works

Three layers of anonymity, one Rust workspace.

No trusted ceremony, no hand-waving: the circuit, the prover and the tree are all in-repo and testable at mainnet scale.

Shield

Outputs are Pedersen commitments appended to a sparse Merkle tree at mainnet depth 2³². The commutative Poseidon tree hash (t=3, x⁵ S-box) removes direction bits from witness paths.

Prove

A single-region Halo2 circuit (FcmpCircuit, 65 rows per permutation) proves in zero knowledge that the spend key is a member of the global tree — revealing only a nullifier.

Settle

Consensus verifies the IPA proof and registers the nullifier: double-spends are impossible, while amounts, recipients and history stay untraceable.

FCMP++-style membership

The spend proves key material belongs to the global set of all wallet keys at depth 2³² — the FCMP++ design — not a small anonymity ring.

Transparent proving system

halo2_proofs 0.3.5 (zcash lineage) with IPA commitments over the Pasta (Vesta) scalar field. No trusted setup — every constraint is auditable.

Constant-memory tree

A sparse Merkle frontier with empty-subtree-root padding computes roots and auth paths in O(leaves + depth) — the naive approach would need ~137 GB of RAM.

Monero atomic swaps

Cross-group Schnorr DLEq proofs, a hashlock state machine (Offered → … → Claimed/Refunded) and a length-prefixed P2P protocol with tamper-evident offer ids — since v0.9 the hashlock is proven in-circuit and CLAIM/REFUND are enforced at consensus level.

Ethereum bridge & wOpacus

Quorum-gated ERC-20 wrapper deployed to Sepolia, EIP-155 signer, Uniswap Router02 calldata builders and a JSON-RPC client — a full DEX/bridge toolchain.

Daemon & CLI out of the box

opacusd runs the net and swap services and hands authenticated connections to the swap plane; opacus-cli drives the shielded wallet — build, prove, self-verify before any state mutation.

Quick start

From clone to shielded node in four commands.

Prerequisites: a recent stable Rust toolchain (rustup) and Git.

$ git clone https://github.com/opacusio/opacus.git
$ cd opacus
$ cargo build --release
$ cargo test --workspace            # 441 tests

# real (non-mock) IPA prover tests:
$ cargo test -p opacus-zk --features real-prover

# run a local swap node (daemon: opacusd):
$ cargo run --release -p opacus-node --bin opacusd

# or a full testnet node via the canonical CLI:
$ cargo run --release -p opacus-cli --bin opacus -- start --network testnet

Prefer mining? opacus-miner ships a PoW engine with stats and config. Ethereum-side contracts build with Foundry: forge test --root contracts.
